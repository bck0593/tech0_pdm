# 週一チェック モック

## 動かし方（Windows）
1. Python 3.10 以上を入れる
2. このフォルダでコマンドプロンプトを開き、次を実行
   ```
   pip install -r requirements.txt
   ```
3. `.env` の `OPENAI_API_KEY=` にAPIキーを書く
4. 起動
   ```
   streamlit run app.py
   ```
5. ブラウザが開く。左下の「動作モード」が **AI** になっていれば本物のAIで動いている（キーがなければ「台本」）

## 中身
- app.py：画面（受講生／講師・TA）
- engine.py：試問のしくみ（台本モード／AIモード）
- db.py：記録（SQLite の mock.db。起動時に架空の90人分を作る。消すと作り直す）

## 注意
- `.env` とキーは人に渡さない
- AIモードでは、受講生の答えの文字起こし・聞き返し・判定・聞き返しの読み上げでAPIを使う（1回の試問で数円〜十数円の目安）
